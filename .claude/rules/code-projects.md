# Code projects

- One project = one folder + one row in `code/index.md`. A project with its own published Git repo → add its path to the root `.gitignore`.
- Every non-trivial project carries its own `CLAUDE.md` (stack, build/test commands).
- Durable knowledge acquired while coding (gotchas, architecture decisions) → brain note in the relevant area, not only in the code.
- Deploying a project → runbook in `docs/<project>/runbook/`.
