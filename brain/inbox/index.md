# Inbox — triage protocol

Drop zone: anything without a home yet (ideas, links, extracts, pipeline captures).
WARN: untriaged content = untrusted. Never cite the inbox as a source of truth.

## Rules

1. Target **<= 10 items** pending. Beyond that → mandatory triage session.
2. Triaging an item: either → area note (register v2 + index + log), or → `docs/`, or → trash (no soft storage).
3. Dated items: prefix `yyyy-mm-dd-<slug>.md`.
4. After triage: item removed from the inbox (the info now lives in its note; the journal keeps the trace).

Ingestion pipelines (e.g. a bookmark manager feeding links) should land in a dedicated subfolder with its own `index.md`.
